App tech stack watch

Which SDKs does an iOS app ship with, and where has it charted? PeekPanda stores dated technology evidence per app: SDK names found in the app package grouped by category, plus source-reported best chart positions over a rolling 90 days. Paste the answers for one or more apps and this page lays them out, and given an earlier run, lists what changed. Nothing leaves your browser; this page never calls the API.

An advertising-network identifier does not prove active ad buying, and an SDK that is not listed is not proof the app lacks it. Best ranks are not a daily history or a current position.

Where to get the JSON

The answer needs a PeekPanda account (scope context:read), counts as one call toward your plan's daily API and MCP allowance, and never starts collection. See Get competitor technology and plans and refreshes:

curl 'https://api.peekpanda.com/v1/competitors/ios/571800810/technology' \
  --header "Authorization: Bearer $PEEKPANDA_TOKEN" > tech.json

Identifiers in the answer that are not readable names (keys, IDs, URLs) are counted but never printed here.
